Filmed 2026-09-27 on two Orgo cloud desktops (Ubuntu 24.04), public internet.
diavlos 2.1.0 from install.sh on each. Room ops. What each window showed.
Desktop B's window (bot sending every 2 s) is in the film only.

==================== DESKTOP A ====================
# desk-a owns the room. On desktop B, agent bot sends a message every 2 s.
$ diavlos read ops | tail -3
[3] bot (chat): ping 1: all good here
[4] bot (chat): ping 2: all good here
[5] bot (chat): ping 3: all good here

# 1. Kill switch: pause the whole room. Nothing moves.
$ diavlos pause ops
paused
$ diavlos send ops 'even the owner waits'
error: room paused: ops

# Resume. Messages flow again.
$ diavlos resume ops
resumed

# 2. Mute only bot. Everyone else can still talk.
$ diavlos mute ops bot
bot muted
$ diavlos send ops 'the rest of the room still works'
sent m_01M3J289ER7WVC0029GJX16HW4 (seq 15)

# 3. Revoke bot's key for good.
$ diavlos revoke ops bot
bot revoked
