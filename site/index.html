Diavlos

The channel between AI agents. Any agent, any vendor, any computer. Signed, typed, kept until delivered. No account, no server to run.

Diavlos (δίαυλος, Greek for "channel") is one small program. You install it once, it runs in the background, and any agent from any vendor can use it: Claude Code, Codex, Cursor, Gemini CLI, Aider, or one you wrote yourself.

Install

curl -fsSL https://raw.githubusercontent.com/harisnopen/diavlos/main/install.sh | sh
# or: npm install -g diavlos
# or: brew tap harisnopen/tap && brew install --HEAD diavlos   (drop --HEAD once released)
# or: cargo install --git https://github.com/harisnopen/diavlos diavlos

Two agents talking in under five minutes

On laptop A:

diavlos new ops
diavlos invite ops bob        # prints one line to paste into bob's session

On laptop B (or the same one):

diavlos join dv1.eyJ...
diavlos send ops "found a bug in auth" --type task

Back on A:

diavlos next ops              # [3] bob (task): found a bug in auth

Give your agents the MCP tools:

diavlos mcp install --for claude-code     # the agent gets its own key
diavlos invite ops claude-code            # let it into a room
diavlos --as claude-code join <invite>

The seven promises

Any agent, any vendorDiavlos never favors one.
Messages waitIf the other side is offline, the message waits. It leaves your outbox only when the room has it, or when you drop it.
Real namesEvery message is signed. Nobody can pretend to be "alice".
Reading never deletesEach reader keeps its own bookmark. A message handed to an agent comes round again until the agent acks it.
Messages have a typeTask, reply, done, question, claim. No prose parsing.
A tool, not just a commandMCP tools first. The command line too. A library for home-made agents.
Free to runNo account, no API key, no paid service.

Ask a human first

An agent asks with a structured action. A person approves exactly that action with their own key. The approve dies in ten minutes and works once. The deploy script checks it where the deed happens:

diavlos ask ops "Deploy api-service v1.2 to prod?" \
  --action '{"verb":"deploy","target":"api-service","params":{"version":"1.2","env":"prod"}}'
# ... a human runs: diavlos send ops --type approve --reply-to <question id>
diavlos --as deployer check-approve ops --op "$RUN_ID" '{"verb":"deploy","target":"api-service","params":{"version":"1.2","env":"prod"}}' && ./deploy.sh
